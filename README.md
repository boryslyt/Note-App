# 📝 Notes App
A simple and responsive Notes App built with React.

The app allows users to create notes, mark them as completed, delete them, and filter notes by their status. Notes are saved in localStorage, so they remain available after refreshing the page.

## 🚀 Features
- Add new notes
- Delete notes
- Mark notes as completed
- Undo completed notes
- Filter notes by:
  - All
  - Active
  - Completed
- Notes and completed notes counter
- Data persistence with localStorage
- Responsive design for desktop and mobile
